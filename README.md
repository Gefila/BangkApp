
# BangkApp

**BangkApp** adalah aplikasi mobile yang menampilkan informasi seputar kuliner, penginapan (hotel), dan rental mobil di wilayah Bangka. Aplikasi ini dikembangkan sebagai **project akhir mata kuliah Desain dan Pemrograman Mobile** dan berfokus pada tampilan antarmuka pengguna (UI) tanpa integrasi database.

## 📱 Fitur Utama

- Tampilan kategori: Makanan, Hotel, dan Rental Mobil
- Navigasi antar halaman menggunakan Intent
- Desain UI responsif dan mudah digunakan
- Informasi ditampilkan secara statis (tanpa backend/database)

## 🛠️ Teknologi yang Digunakan

- **Platform**: Android Native
- **Bahasa Pemrograman**: Kotlin
- **IDE**: Android Studio

## 💡 Konsep yang Digunakan

- **Activity dan Intent**  
  Navigasi antar halaman dilakukan menggunakan `Intent`, berpindah dari satu activity ke activity lainnya.

- **Layouting dengan XML**  
  Menggunakan LinearLayout, ConstraintLayout, dan ScrollView untuk mengatur tata letak antarmuka.

- **Komponen UI Dasar**  
  Seperti `TextView`, `ImageView`, `Button`, dan `CardView` untuk membangun tampilan.

- **Resource Management**  
  Memanfaatkan folder `res/` (drawable, string, colors, dimens) untuk mengatur aset secara modular.

- **Modularisasi Tampilan**  
  UI dibagi ke dalam beberapa activity untuk setiap kategori (Makanan, Hotel, Rental).
